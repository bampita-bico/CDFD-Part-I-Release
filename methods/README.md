# CDFD/AFL Methods Consolidation

This directory is the proposed single, modest publication spine for the
cross-domain CDFD/AFL material. It does not preserve the many domain papers as
separate claims. Its limited subject is an auditable way to declare a toy model
and record what the execution did and did not establish.

- [`paper.md`](paper.md): methods-paper draft.
- [`model-declaration.schema.json`](model-declaration.schema.json): portable
  declaration-record schema.
- [`examples/torus-knot-negative-result.json`](examples/torus-knot-negative-result.json): a
  completed negative-result record.
- [`CONSOLIDATION_REGISTER.md`](CONSOLIDATION_REGISTER.md): archive and
  publication disposition.
- [`METHODS_PAPER_READINESS.md`](METHODS_PAPER_READINESS.md): required
  evaluation before submission.

The schema is a documentation and provenance convention, not a new physical,
biological, or clinical model standard. It is intentionally subordinate to
domain-native representations and benchmarks.
