## How to use

1. Create **one Zenodo record per PDF** under `Part_I_Fundamental_Physics/PDFs/`.
2. Paste the **Plain text (recommended)** block into Zenodo’s Description field
   unless the UI explicitly accepts HTML.
3. Use the **HTML** block only on platforms that render HTML. Zenodo is safer
   with plain text.
4. Keep titles exactly as listed — they match the compiled PDFs.
5. Suggested upload type: **Publication → Preprint** (or Working paper).
6. Reuse the shared keyword bank at the end of this file.

**Uniform framing**

- Papers **01–10**: model-level / internal consistency.
- Papers **11–12**: hypothesis-generator / bridge papers.
- Every description states series position, the GitHub path, and that deposit
  alone is not peer-reviewed external experimental validation.
